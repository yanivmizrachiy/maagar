# maagar — מאגר מתמטיקה

מאגר קבצים מסודר לחומרי מתמטיקה, עם הכנה לאתר אינטרנט עברי גדול בעתיד.

הריפו הזה מיועד ל:

- שמירת קבצים אמיתיים בלבד.
- סיווג חומרים לפי שכבה, תחום, נושא, סוג, מחבר, שנה ורמה.
- שליפה חכמה של קבצים ומשימות לפי מטא־דאטה.
- הכנת מבנה נתונים לאתר אינטרנט שבו יוצגו החומרים לפי כפתורים, שכבות ורמות.
- תמיכה עתידית בהטמעת קבצים/משימות כאשר אפשר, או קישור רגיל כאשר הטמעה אינה אפשרית.

## מבנה אתר עתידי

בעמוד הראשי יהיו ארבעה כפתורים מרכזיים:

1. שכבת ז׳
2. שכבת ח׳
3. שכבת ט׳
4. חטיבה עליונה

בכל שכבה ז׳/ח׳/ט׳ יהיו ארבעה אזורים:

1. אלגברה
2. גיאומטריה
3. משימות מסכמות
4. מבחנים

בחטיבה העליונה יהיו שלושה כפתורים:

1. בגרות במתמטיקה ברמת שלוש יחידות
2. בגרות במתמטיקה ברמת ארבע יחידות
3. בגרות במתמטיקה ברמת חמש יחידות

כל רמה בחטיבה העליונה תקבל צבעי פרימיום שונים, כמוגדר ב־`metadata/site-structure.json`.

## קבצים מרכזיים

- `RULES.md` — מקור האמת הראשי והמחייב.
- `AGENTS.md` — הוראות עבודה ל־GPT / Codex / AI.
- `metadata/index.json` — אינדקס הקבצים והפריטים הפעילים.
- `metadata/taxonomy.json` — מילון הסיווגים.
- `metadata/authors.json` — מילון מחברים.
- `metadata/site-structure.json` — מבנה ניווט ועיצוב לאתר העתידי.

## כלל עבודה

לפני כל פעולה בריפו יש לקרוא את `RULES.md`.

אין דמו, אין קבצים פיקטיביים, אין מטא־דאטה מומצא, ואין הצגה של חומר כאילו הוא קיים אם הוא לא מופיע באינדקס התקף.
