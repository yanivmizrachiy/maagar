# maagar

מאגר קבצים מסודר לחומרי מתמטיקה.

הריפו הזה הוא מאגר GitHub בלבד — לא אפליקציה, לא אתר, ולא מערכת תצוגה.

המטרה שלו היא:
- לשמור קבצים אמיתיים שאתה מוסיף
- לסווג אותם בצורה עקבית
- לאפשר שליפה עתידית לפי כיתה, יח"ל, נושא, סוג מסמך, סוג מבחן, שאלון, שנה, מחבר ותגיות
- לאפשר ל-GPT או לכל AI אחר להבין בדיוק איך לעבוד עם הריפו

## קבצים מרכזיים
- `RULES.md` — מקור האמת הראשי והמחייב
- `AGENTS.md` — הוראות עבודה מפורטות ל-GPT / AI
- `metadata/index.json` — אינדקס הקבצים
- `metadata/taxonomy.json` — מילון הסיווגים
- `metadata/authors.json` — מילון מחברים

התחל תמיד מקריאת `RULES.md`.
